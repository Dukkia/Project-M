# M-Controller Pro (Global Hook)

A premium macro controller for Electron featuring:
- Global keyboard hook using `node-global-key-listener`.
- Profile-based macro management with file persistence.
- Hardware communication via Web Serial (Pico compatible).
- Modern, glassmorphic UI designed with React and Vite.

## Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run electron:dev
```

## Build

```bash
# Build production bundle
npm run electron:build
```
